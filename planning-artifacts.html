Key features

  • Multiple html pages that the player traverses through depending on story choices they click
  • At least 3 different endings
  • One “extra” element not covered by Code.org: Using JavaScript to make a prompt for the user to enter their protagonist’s name which is then used to greet them

Story guide / Story order

  1. Start screen where user is prompted to give the protagonist a name
  2. Protagonist wakes up in the morning and is INTENSELY craving a bag of chips for no reason (Eat something at home = Healthier breakfast ending)
  3. The protagonist gets to the store and finds that there is a really big dragon guarding and hoarding the store. (Not helping cashier = Healthier breakfast ending)
  4. The cashier is relieved and asks how you’re going to help (Confront the dragon right away by yourself = Trampled ending) (Call 911 = Nuked ending)
  5. Protagonist tries to recruit crowd (Insulting crowd = Jumped ending) (Insulting dragon = Chips / Good ending)
